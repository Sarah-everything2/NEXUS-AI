# Contributing

Thank you for your interest in NEXUS AI.

## Development
1. Fork or clone the repository.
2. Create and activate a Python virtual environment.
3. Install dependencies from `requirements.txt`.
4. Make focused changes and explain their purpose.
5. Run relevant checks for the components you changed.
6. Submit a pull request describing the implementation, tests and limitations.

## Contribution Expectations
- Preserve existing integrations and user configuration.
- Never commit credentials, OAuth tokens, `.env` files, private settings or local backups.
- Avoid destructive filesystem or Git operations.
- Keep external actions disabled unless explicitly configured and authorized.
- Preserve approval gates, emergency stops, audit trails and risk limits.
- Document new environment variables and configuration options.
- Do not claim that untested functionality is production-ready.

## Pull Requests
Include a concise summary, relevant test results, configuration changes and any known limitations. Never include real credentials or private account data in examples.
