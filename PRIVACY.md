# Privacy Policy

## Overview
NEXUS AI is designed to run locally where practical. Actual data handling depends on enabled features, local configuration, connected providers and third-party services.

## Data That May Be Processed
Depending on enabled integrations, NEXUS AI may process:
- User prompts, task inputs and generated content.
- Local workspace files and application memory.
- OAuth credentials, API tokens and service configuration.
- Trading account information, market data and mining telemetry.
- Video files, publication metadata and social account information.

## Storage and External Services
Some information may be stored in local configuration, logs, memory databases or token stores. Enabled integrations may transmit data to their respective providers. Consult each provider's privacy policy and configure only services you intend to use.

## User Responsibilities
- Protect local configuration, credentials, logs and backups.
- Do not commit personal data or secrets to public repositories.
- Review permissions and data-sharing settings before connecting services.
- Disable integrations you no longer use.

## No Blanket Privacy Guarantee
Privacy characteristics depend on the selected model, providers, integrations and deployment environment. Users should inspect the implementation and configuration before handling sensitive information.
