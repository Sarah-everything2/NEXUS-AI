# Airdrop Management Skill

## Capabilities
- Discover potential airdrops.
- Research project legitimacy.
- Track eligibility requirements.
- Monitor deadlines.
- Organise campaign tasks.
- Track completed activities.
- Monitor reward announcements.

## Safety
- Never request seed phrases.
- Never expose private keys.
- Never sign suspicious transactions.
- Require approval for wallet transactions.
- Flag scams and suspicious websites.
- Never guarantee rewards.
